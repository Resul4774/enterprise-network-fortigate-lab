# EVE-NG Lab

This directory contains the exported EVE-NG lab topology.

## Requirements

- An EVE-NG installation compatible with the lab
- Matching network appliance images installed separately
- Appropriate licenses and access to the required software

## Import

Download the exported ZIP archive from this repository and import it through the EVE-NG web interface. Do not assume that appliance images are included in the archive.

The topology may require interface, image, or configuration adjustments when imported into another environment.
